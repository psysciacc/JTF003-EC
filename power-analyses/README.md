# power-analyses

Simulation-based power analyses.

- `power-analyses.Rmd` / `.html`: the power analysis report.
- `PSA_pwr_script_cluster.R`: simulation script, written to run on a cluster.
- `PSA_sim_wrapper.sh`, `PSAsubmit.sh`: shell scripts for submitting the simulations as cluster jobs.
- `power_sim_results.csv`: simulation output.

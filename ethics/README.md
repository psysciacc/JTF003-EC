# ethics

Ethics documentation for the project.

- `Essex Ethics Documents/`: the lead site's ethics application, approval, modification, and modification approval.
- `Local Ethics Approval/`: approval letters from collaborating sites that obtained their own local approval. Files are named `<lab ID>_<lead author>_<institution>`.
- `Rely on Essex/`: documentation for sites that relied on the Essex approval.
- `No Ethics/`: documentation for sites that did not require ethics approval.

# reading-pretest

Everything for the reading-time pretest.

- `Questionnaire Reading Pretest.docx` / `.qsf`: the questionnaire (`.qsf` imports into Qualtrics).
- `Pre2.csv`: processed data. Participants who did not fully complete the study and those who also did the manipulation pretest were already removed.
- `codebook_reading_test.xlsx`: codebook for `Pre2.csv`.
- `Reading_pretest_code.R`: analysis code. Reads `Pre2.csv` and writes `Figure S1.png` in this folder.
- `Figure S1.png`: supplementary figure produced by the analysis code.

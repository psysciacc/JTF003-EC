# manipulation-check

Analysis of the manipulation pretest.

- `manip_test_noOverlap_anonim.csv`: anonymized pretest data (no participant overlap).
- `save_dataset_pretest.R`: script that prepares and saves the dataset.
- `manipulation_check_report.Rmd` / `.html`: analyses and results.

A codebook for these data is in `../pre-test/Manipulation Pretest/codebook_manip_test.xlsx`. `../analysis-code/analysis_code.Rmd` reads the CSV from this folder.

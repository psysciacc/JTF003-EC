# manipulation-check

Everything for the manipulation pretest.

- `Questionnaire Manipulation Pretest.docx` / `.qsf`: the questionnaire (`.qsf` imports into Qualtrics).
- `manip_test_noOverlap_anonim.csv`: anonymized pretest data (no participants who also did the reading pretest).
- `codebook_manip_test.xlsx`: codebook for the data.
- `save_dataset_pretest.R`: script that prepares and saves the dataset.
- `manipulation_check_report.Rmd` / `.html`: analyses and results.

`../analysis-code/analysis_code.Rmd` reads the CSV from this folder.

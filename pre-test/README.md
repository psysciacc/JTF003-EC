# pre-test

Materials, data, and codebooks for the two pretests.

- `Manipulation Pretest/`: questionnaire (`.docx`, `.qsf`), codebook, anonymized data, and analysis report for the manipulation pretest.
- `Reading Pretest/`: questionnaire (`.docx`, `.qsf`), codebook, and analysis code (`Reading_pretest_code.R`) for the reading-time pretest.
- `Pre2.csv`, `Pretest2.R`, `Codebook.txt`: data, analysis script, and codebook for the reading-times pretest (`Codebook.txt` describes `Pretest2.csv`).
- `Figure S1.png`: supplementary figure.
